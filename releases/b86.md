### Downloads

**Standalone (run directly, no other files needed):**
- AngelServ-b86-linux-x86_64 / AngelServ-b86-windows-x86_64.exe - dedicated game server
- AngelMaster-b86-linux-x86_64 / AngelMaster-b86-windows-x86_64.exe - master/listing server
- OzPack-b86-linux-x86_64 / OzPack-b86-windows-x86_64.exe - asset packer CLI

**Requires the full System-b86.zip** (ships raylib/GLFW DLLs, GameData, INI templates, run scripts):
- Angels95-b86-linux-x86_64 / Angels95-b86-windows-x86_64.exe - game client
- AngelEd-b86-windows-x86_64.exe - editor (Windows only; Win32 native panels)

Platform notes:
- Linux binaries are dynamically linked against the distro glibc; run on a modern x86_64 Linux.
- `AngelEd` is Windows-only (Win32 API); there is no Linux build.
- For servers, see `System/angels95-serv.service` for VPS systemd units and `System/OzServer.ini` for config (`--bind 0.0.0.0` to accept remote clients).
